# Malik Saaka

Personal portfolio for Malik Saaka, published with GitHub Pages at [maliksaaka.com](https://maliksaaka.com).

Static HTML, CSS, and JavaScript with no build step. `index.html` is the home page, `work/company.html` is the project detail page, and images and audio live in `assets/`.

GitHub Pages serves the root of `main`. `CNAME` sets the custom domain. `.nojekyll` disables Jekyll processing so the files are published as-is.
